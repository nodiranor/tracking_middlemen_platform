Shippo va Narvar modelidagi O'zbekiston logistika orchestrator dvigateli. Marketplacelar (OLX, Uzum, Asaxiy) va Kuryerlar (Fargo, EMU, BTS, UzPost, Yandex) uchun ikki tomonlama to'liq dasturlash qo'llanmasi.

Ikki Tomonlama Platforma Arxitekturasi

Bizning xizmatimiz vositachi (middleware) logistika dvigateli bo'lib, bozorning har ikki tomonini bitta yagona standartlashtirilgan protokol orqali birlashtiradi:

1-Tomon: Talab Tomoni (Demand Side)

Marketplacelar & Do'konlar

OLX, Uzum, Asaxiy, Zoodmall yoki mustaqil e-commerce do'konlari.

  • Bitta API: Barcha kuryerlar uchun yagona integratsiya.
  • 100% White-Label: Xaridor bizning dvigatelni hech qachon ko'rmaydi.
  • Ichki UI Widget: Xaridor marketplace saytidan chiqmagan holda kuzatadi.
2-Tomon: Ta'minot Tomoni (Supply Side)

Kuryerlik Kompaniyalari

Fargo Express, EMU, BTS Cargo, UzPost, Yandex Delivery.

  • Avtomatlashtirilgan buyurtma oqimi: Marketplacedan to'g'ridan-to'g'ri manifest qabul qilish.
  • Standartlashtirilgan Telemetriya: GPS va ombor skanerlarini bitta webhookka uzatish.
  • 验货照 (Sifat tekshiruvi): Tovarning tekshiruv suratlarini yuklash protokoli.

Yetkazib Berish Xizmati Bo'yicha Eng Yaqin Yo'nalish Hisobi

Dvigatelimiz shunchaki to'g'ri chiziqli (haqiqiy bo'lmagan) masofani emas, balki O'zbekiston avtomagistral tarmog'i bo'yicha eng yaqin xavfsiz ichki tranzit yo'nalishini hisoblaydi.

O'zbekiston Ichki Tranzit Qoidasi (Qozog'iston Chegarasini Kesib O'tmaslik):
Toshkent va Samarqand o'rtasidagi sovet davridan qolgan eski M39 yo'li Qozog'iston hududiga kirib chiqadi. Bizning dvigatelimiz ichki jo'natmalar uchun Guliston, Yangiyer, Dashtobod va Zarbdor orqali o'tuvchi yangi janubiy aylanma yo'lni (386.2 km, 0 ta chegara o'tishi) tanlaydi va real yo'l masofasi asosida kuryerlik tarifini dinamik hisoblab beradi.
Tarifni hisoblash formulasi:
Narx = Baza_stavkasi + (Yo'l_masofasi_km × Kuryer_tarif_koeffitsiyenti) + (Haqiqiy_vazn_kg × Vazn_tarifi)

1. Ko'p Kuryerlik Tariflarini Olish & Yo'nalish Hisobi

Marketplace xaridori buyurtma berish paytida ushbu endpointga murojaat qilinadi. Dvigatel eng yaqin avtomobil yo'nalishini hisoblab, barcha ulangan kuryerlar (Fargo, EMU, BTS, UzPost, Yandex) narxlari va yetkazish vaqtlarini bir vaqtda qaytaradi.

GET /v1/rates
ParametrTuriIzoh
origin majburiy string Jo'natuvchi shahri (masalan: Toshkent).
destination majburiy string Qabul qiluvchi shahri (masalan: Samarqand yoki Buxoro).
weight_kg float Tovar fizik vazni (kg). Standart qiymat: 2.0.

Python
curl -X GET "http://localhost:8080/v1/rates?origin=Toshkent&destination=Samarqand&weight_kg=2.0" \
  -H "Authorization: Bearer uz_live_9948201" \
  -H "Content-Type: application/json"

2. Yagona API Orqali Buyurtma Bron Qilish

Xaridor kuryerni tanlaganda, marketplace bitta buyurtma so'rovi yuboradi. Dvigatel tanlangan kuryer tizimida yuk xatini ochadi, UZ88492011223 universal kuzatuv kodini yaratadi va marketplace uchun tayyor o'rnatma URL (embed URL) qaytaradi.

POST /v1/shipments
MaydonTuriIzoh
carrier_code majburiy string Tanlangan kuryer: fargo, emu, bts, uzpost, yandex.
marketplace_id majburiy string Platforma identifikatori: olx, uzum, asaxiy.
external_order_no string Marketplacedagi buyurtma raqami (masalan: OLX-884920).
item object Haqiqiy xarid qilingan tovar nomi, narxi (UZS), rasmi va to'lov holati.
cURL
JavaScript (Fetch)
curl -X POST "http://localhost:8080/v1/shipments" \
  -H "Authorization: Bearer uz_live_9948201" \
  -H "Content-Type: application/json" \
  -d '{
    "external_order_no": "OLX-884920",
    "carrier_code": "fargo",
    "marketplace_id": "olx",
    "sender_city": "Toshkent",
    "recipient_city": "Samarqand",
    "item": {
      "title": "Apple MacBook Pro 14\"",
      "price": 21500000,
      "currency": "UZS",
      "payment_status": "To'langan (Click / Payme)"
    }
  }'

3. Marketplace Saytiga Xaritani O'rnatish (<uz-tracking-view>)

Xaridor tashqi kuryer vebsaytiga yuborilmaydi. Marketplace dasturchisi buyurtma sahifasiga quyidagi 2 qator kodni qo'yadi. Xarita Pinduoduo/Taobao uslubida silliq 3D vector grafikasi bilan to'g'ridan-to'g'ri marketplace sahifasida ochiladi:

HTML Drop-in Component
<!-- 1. Bizning tezkor CDN skriptimizni ulang -->
<script src="http://localhost:8080/widget.js" async></script>

<!-- 2. Marketplace buyurtma sahifasiga maxsus tegni joylang -->
<uz-tracking-view 
  tracking-code="UZ88492011223" 
  brand="olx" 
  theme="light" 
  lang="uz">
</uz-tracking-view>
Dizayn avtomatik moslashuvi:
brand="olx" bo'lganda yo'nalish chizig'i va tugmalar to'q yashil (#002f34) bo'ladi.
brand="uzum" bo'lganda yo'nalish Uzum binafsharang (#7000ff) bo'ladi.
Xaridor hech qachon uchinchi tomon yoki orqa fondagi dvigatel nomini ko'rmaydi.

2-Tomon: Kuryerlik Xizmatlari Integratsiyasi (Supply Side)

Kuryerlik kompaniyalari (Fargo Express, EMU, BTS Cargo, UzPost) bizning platformamizga qanday ulanadi? Ular o'z tizimlaridan buyurtmalarni qabul qilish va ombor skanerlarini uzatish uchun 3 ta asosiy endpointdan foydalanadilar.

POST /v1/carrier/manifests

Kuryerlik kompaniyasi saralash tizimi marketplacelardan ularga tushgan jo'natmalar reestrini (Pickup Manifest) yuklab oladi.

cURL
curl -X POST "http://localhost:8080/v1/carrier/manifests" \
  -H "Authorization: Bearer carrier_key_fargo" \
  -H "Content-Type: application/json" \
  -d '{ "carrier_code": "fargo" }'
POST /v1/carrier/events

Kuryer yoki saralash ombori posilka shtrix-kodini skaner qilganda yoki GPS koordinatasini jo'natganda ushbu endpointga push yuboradi:

MaydonTuriIzoh
tracking_code majburiy string Posilka raqami (masalan: UZ88492011223).
status string IN_TRANSIT, DEST_HUB_IN, OUT_FOR_DELIVERY, DELIVERED.
checkpoint_name string Ombor yoki post nomi (masalan: Jizzax M39 Nazorati).
lat / lng float Kuryer mashinasining real GPS koordinatalari.
cURL
curl -X POST "http://localhost:8080/v1/carrier/events" \
  -H "Authorization: Bearer carrier_key_fargo" \
  -H "Content-Type: application/json" \
  -d '{
    "tracking_code": "UZ88492011223",
    "status": "IN_TRANSIT",
    "city": "Jizzax",
    "checkpoint_name": "Jizzax M39 Nazorati",
    "lat": 40.1158,
    "lng": 67.8422,
    "description": "Jo'natma saralashdan o'tdi va Samarqandga yo'l oldi."
  }'

Status Normalizatsiya Matritsasi (UZ-LTS 8-Holat)

Har bir kuryerlik kompaniyasida o'zining ichki status kodlari bo'ladi. Dvigatel ularni barcha marketplacelar tushunadigan yagona 8 ta xalqaro standart holatga o'giradi:

Dvigatel Standart Statusi Fargo Express Kodingi EMU Express Kodingi BTS Cargo Kodingi Mijozga Ko'rinishi (Xaritalash)
ORDER_CREATED 10 - New Order CREATED NEW_DOC Buyurtma rasmiylashtirildi
PICKED_UP 20 - Taken by Courier PICKED RCV_CLIENT Kuryer qabul qildi
ORIGIN_HUB_IN 30 - Arrived Sergeli HUB_SCAN WH_IN_TASH Bosh saralash omborida (验货 tekshiruv)
IN_TRANSIT 40 - On Linehaul Route AIR_AVTO_TRANSIT EN_ROUTE_TRUCK Shaharlararo magistralda (M39)
DEST_HUB_IN 50 - Arrived Regional Hub REG_WH WH_SAM Hududiy saralash markazida
OUT_FOR_DELIVERY 60 - Assigned to Courier LAST_MILE COURIER_OUT Kuryer eshikkacha yetkazmoqda
DELIVERED 70 - Signed & Handed DELIVERED SUCCESS Mijozga topshirildi (Xavfsiz bitim yakunlandi)
